Student Result Portal
=====================

The Student Result Portal is a lightweight web application designed to help students access their academic results securely. It provides a straightforward interface for viewing GPA, class awards, and subject-specific grades.

Key Features:
- Secure login using registration numbers.
- Automated GPA and Class Award display.
- Dynamic breakdown of subject results.
- Clean, responsive user interface.

Technical Stack:
- HTML5, CSS3, JavaScript
- Client-side data handling for maximum speed.
